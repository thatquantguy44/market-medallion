- Every official linked historical year page from 1990 onward and the current
  calendar is archived and characterized. Exact page expectations and exclusions
  come from archived source inventories, without guessed filenames or counts.
- Notation votes and cancelled meetings have source-specific, fixture-backed
  dispositions. The 2020 cross-reference resolves only to the explicitly identified
  meeting and retains its original claim/representation links.
- A bounded native document/addendum/asset sample and rejected/truncated cases
  demonstrate byte preservation and blocked success on missing/invalid inputs.
  This gate does not certify a full original-document backfill or text extraction.
- Before applying existing local FOMC migrations, preserve a verified backup and
  compare all existing capture receipts/bytes, inventory pointers and namespaces
  before/after. Migrations must preserve old capture IDs and observed clocks.
- Offline tests, real isolated-backend checks, lint/format, package build and
  artifact checks pass. Save sanitized closeout evidence and update the pipeline
  register/handoff. Jobs remain absent and schedules remain stopped.

All closeout gates passed. [Machine-readable evidence](evidence/t03_closeout.json)
records the 33-page census, 371 meetings, 470 declared references, 14 bundled
cross-references and zero unresolved/unaccounted inventory cases. The December
30, 1994 empty official minutes href is a visible `unavailable` source outcome,
not a fabricated document or a silent completeness claim. Unknown future source
labels and unsupported content still block promotion.

Local migrations are applied. The canonical archive holds 72 captures: 38
inventories, 12 document representations and 22 PNG assets. All pass exact
filesystem/PostgreSQL readback. The original five captures retain receipt bytes,
identifiers and clocks, as reverified against the pre-migration backup. One
1990-onward metadata snapshot and eight dependency checks are committed.
The post-closeout backup restores all 17 tables, the current pointer, native
evidence, captures and dependency checks exactly. Disposable restore databases
were removed. Other namespaces and schedules remain unchanged.

Source exceptions are resolved through fixtures and retained raw evidence:

- Explicit notation votes and cancelled meetings are nonmeeting exclusions.
- Crisis-period cross-references resolve only to an unambiguous same-year source
  meeting, preserving slash/hyphen ranges and original source claims.
- Cross-month dates, nounless unscheduled sessions, sized PDF captions and legacy
  HTTP references are supported from the observed source grammar. Only reviewed
  legacy references upgrade to HTTPS; outbound requests remain HTTPS-only.
- The 1993/2003 classic HTML body profile preserves complete originals, excludes
  only reviewed decorative/edge scaffolding and keeps unknown assets active as
  issues. Modern article/SEP profiles remain independent.
- The standalone October 2019 accessibility ZIP contains a conference transcript
  and presentation materials. It remains outside minutes scope. Its optional
  manual-review guard failure is recorded separately with no retained first body;
  it is excluded from every pipeline/acceptance capture count. The bounded retry
  retained the full ZIP before directory inspection, without extraction/execution.

Final verification: **918 tests passed, 38 optional skips**; all **198 FOMC
checks passed with PostgreSQL enabled**, including 28 isolated backend checks.
Ruff lint/format, diff checks and package/artifact checks passed.
