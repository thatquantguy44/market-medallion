# FOMC 1997–2026 backfill contract

User-selected continuation, 2026-11-13, on the existing PR #18 branch. Acquire
all officially listed, released, in-scope minutes references for 1997 through
2026 using the existing pipeline and Dagster job. The prior 1990–1996 acceptance
remains the baseline. This is a one-time backfill; recurring acquisition is a
separate operating decision.

The no-HTTP plan divides the range into 15 two-year batches with 391 planned
references, including shared/reused references. Each batch fits the existing
limits: two years, 40 documents, 100 data requests, 100 assets, 100 MB and 600
seconds, with three source-owned attempts and one-second pacing. Reconcile the
final selection against refreshed official inventories, rather than treating
this initial count or an assumed annual meeting count as authoritative.

For each batch, require a successful actual Dagster run, coherent committed
inventory/text/chunk pointers, healthy readback, every selected reference archived,
exact text/chunk spans and PDF page citations. Preserve review-required outcomes
and retain originals independently of extraction quality. Existing receipts,
capture-time first-seen clocks and append-only rows must remain unchanged.

Before advancing, restore the complete FOMC schema into a disposable database
and the canonical filesystem archive into a disposable root; compare table and
file hashes. Replay the selected catalogs, all original captures/receipt bytes
and the latest operation into a separate empty target with HTTP and text/chunk
transforms disabled. Full backups retain historical catalogs; selected-catalog
replay does not claim to reconstruct every old derived generation. Verify the
matching Dagster success sensor tick and acknowledged Slack delivery.

Verification must hold the source operation advisory lock for a stable snapshot.
If a separate completed authorized operation has advanced the archive, preserve
it and explicitly validate/record its pointer chain; never delete its captures or
claim its requests as belonging to the requested Dagster batch. Durable ignored
checkpoints permit resuming the existing run without downloading it again.

Final acceptance requires all 15 batches and per-year 1997–2026 reconciliation
against the final inventory. Report unavailable, not-listed and unreleased items
separately, including the current year's release cutoff. Do not guess URLs,
backdate availability or certify full-text/OCR accuracy from byte/chunk coverage.
Keep schedules stopped, NAAIM paused, credentials/raw data/backups ignored, and
other pipeline namespaces unchanged. Record sanitized evidence, refresh the
master register/handoff, run regression checks and track the same PR's checks.

## Batching refinement and historical-source support

The original 15-batch primary-reference plan is retained locally. Inspection of
required addenda/images (including 11 PNG assets in the archived June 2017 SEP)
showed that two-year primary counts alone do not reserve enough request headroom.
The no-HTTP plan now has **21 batches**, using individual years for **2009–2020**;
its primary selections still total 391. Existing year/document/request/byte/time
limits remain unchanged. Every actual batch must pass the same gates before
advancing.

Historical pages required fixture-proven support for the reviewed print container,
declared legacy encoding and source-declared charts. The
[attachment profile](attachments_contract.md#historical-print-container-profile--2007-era-pages)
records official evidence, strict decoding, image-folder admission and framing.
All earlier extraction results/IDs remain unchanged. Failed attempts preserve
originals/audit and unchanged published pointers; each receives an additional
restore-tested checkpoint before a reviewed retry. Final evidence must include
these attempts/checkpoints and the final executed batch count explicitly.
